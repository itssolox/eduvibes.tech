Practical 1: Simple Reflex Agent - Vacuum Cleaner

Simple Reflex Agent • PEAS • Discrete Environment

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (12) Exam Variations

Aim & Objective

To design and implement a Simple Reflex Agent for the two-room Vacuum Cleaner World that perceives room status and location, and executes rational cleaning and movement actions based on condition-action rules.

Theory & Core Concepts

PEAS ElementSystem Description for Practical 1
Performance MeasureMaximize clean rooms; minimize energy consumption and time spent moving.
EnvironmentTwo interconnected rooms (A and B); each room status is either Clean or Dirty.
ActuatorsSuction motor (Suck), movement motors (Left, Right).
SensorsDirt detection sensor (Clean/Dirty), Location sensor (Room A / Room B).
  • Agent Concept: An agent is anything that perceives its environment through sensors and acts upon it via actuators.
  • Simple Reflex Architecture: Actions are chosen solely using the current percept (location, dirt status) and condition-action (IF-THEN) rules. The agent maintains zero history or memory of past states.
  • Partial Observability: The agent only perceives the room it currently occupies, not both rooms simultaneously. The global world state is known only to the simulator.
  • Rationality: In this setup, cleaning a dirty room is immediately rational. However, once both rooms are clean, a pure reflex agent with no memory or stopping check would oscillate back and forth indefinitely; the simulation provides the external termination condition.

Step-by-Step Algorithm & Dry Run

  1. Receive current percept (location, status) from the environment.
  2. Evaluate condition-action rules: If status == 'Dirty', action is 'Suck'.
  3. If status == 'Clean' and location == 'A', action is 'Right'.
  4. If status == 'Clean' and location == 'B', action is 'Left'.
  5. Apply action to simulator: update room status or agent location.
  6. Record step in history and repeat until the simulator detects all rooms are Clean.

Complete Python Source Code

Standalone Python 3 implementation with standard library imports only (no extra packages required).

pract1.py 
"""Practical 1: Simple reflex agent - two-room Vacuum Cleaner World.
Run: python pract1.py
Edit LOCATION and ROOMS in main() to change the example.
The agent sees ONLY (current location, current room status).
The simulation, not the reflex agent, stops when both rooms are clean.
"""


def reflex_agent(location, status):
    if status == "Dirty":
        return "Suck"
    if location == "A":
        return "Right"
    return "Left"


def simulate(location, rooms):
    if location not in ("A", "B"):
        raise ValueError("Location must be A or B.")
    if set(rooms) != {"A", "B"} or any(
        value not in ("Clean", "Dirty") for value in rooms.values()
    ):
        raise ValueError("Both rooms must have status Clean or Dirty.")
    rooms = rooms.copy()  # Do not change the caller's dictionary.
    history = []
    while "Dirty" in rooms.values():
        action = reflex_agent(location, rooms[location])
        history.append((location, rooms[location], action))
        if action == "Suck":
            rooms[location] = "Clean"
        elif action == "Right":
            location = "B"
        else:
            location = "A"
    return rooms, history


def main():
    LOCATION = "A"
    ROOMS = {"A": "Dirty", "B": "Dirty"}
    print("Initial:", ROOMS, "Location:", LOCATION)
    final, history = simulate(LOCATION, ROOMS)
    for step, (location, status, action) in enumerate(history, 1):
        print(f"{step}. At {location}, status={status}: {action}")
    print("Final:", final)
    print("Actions:", len(history))
    print("Simulation stopped: both rooms are clean.")


if __name__ == "__main__":
    main()

Detailed Code Explanation

Function-by-function breakdown and key variables explaining the internal logic:

  • rooms is a dictionary: {"A": "Dirty", "B": "Dirty"}. location is either "A" or "B".
  • reflex_agent(location, status) is the decision-making part. Dirty means Suck; clean A means Right; clean B means Left.
  • simulate() validates the input, copies the room dictionary, obtains an action and applies it to the environment.
  • history.append(...) records the old percept and selected action for printing. This recording belongs to the simulator; the reflex function does not read history.
  • The while loop ends when the simulator finds no dirty room. Without a global stopping check or added memory, the simple reflex rules would keep moving between two clean rooms.
  • main() sets the input and prints each action. Change LOCATION and ROOMS for other cases.

Dry run: (A, Dirty) -> Suck -> (A, Clean) -> Right -> (B, Dirty) -> Suck. Both rooms are now clean; total 3 actions.

Practical 2: Model-Based Intelligent Agent - Grid Navigation

Model-Based Agent • Local Sensing • BFS Planning

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (12) Exam Variations

Aim & Objective

To implement a Model-Based Intelligent Agent that navigates an initially unknown obstacle grid by sensing local surroundings, maintaining an internal world map, and planning paths using Breadth-First Search (BFS).

Theory & Core Concepts

PEAS ElementSystem Description for Practical 2
Performance MeasureReach the target goal G with minimum path steps without colliding with obstacles.
Environment2D rectangular grid with Start (S), Goal (G), Free cells (.), and Obstacles (X).
ActuatorsOrthogonal movement (Up, Down, Left, Right).
SensorsLocal sensor revealing current cell and its 4 direct neighbours.
  • Model-Based Architecture: To handle partial observability, the agent maintains an internal world model (self.model) tracking discovered free cells, obstacles, and unexplored cells (?).
  • Unknown Cell Safety: Cells marked ? are never traversed by the planner until confirmed safe/free by local sensing.
  • Dual-Stage Planning: The agent first runs BFS on known free cells to plan to the Goal G. If the goal is not yet reachable through known territory, it plans to the nearest reachable unvisited free cell to explore.
  • BFS Guarantee: On an unweighted grid, BFS finds the shortest route across known free cells to the selected sub-target.

Step-by-Step Algorithm & Dry Run

  1. Initialize internal model grid with ? (unseen) for all cells.
  2. Sense current cell and 4 adjacent orthogonal neighbours; record actual contents into internal model.
  3. Mark current position as visited.
  4. While position != goal:
  5.   a. Run BFS planner targeting the Goal G using only known free cells (., S, G).
  6.   b. If route to goal exists, follow it.
  7.   c. If no route to goal, identify all sensed, free, unvisited cells and BFS plan to the nearest one (exploration mode).
  8.   d. If no exploration target is reachable, terminate with failure (unreachable goal).
  9.   e. Traverse each step of the planned route, sense newly adjacent cells after each move, and replan.

pract2.py 
"""Practical 2: Model-based grid agent with local sensing and BFS planning.
Run: python pract2.py
Edit GRID in main(): S=start, G=goal, .=free, X=obstacle.
Sensor reveals the current cell and four neighbours (manual's extension).
BFS uses ONLY the remembered map. Unknown '?' cells are never traversed.
Explore a reachable unvisited cell when the goal is not yet reachable in the map.
Assumptions: static grid, known dimensions and goal coordinates, reliable sensing.
"""
from collections import deque

DIRECTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]


class ModelBasedAgent:
    def __init__(self, grid):
        if not grid or not grid[0] or any(len(row) != len(grid[0]) for row in grid):
            raise ValueError("Grid must be a nonempty rectangle.")
        if any(cell not in ".XSG" for row in grid for cell in row):
            raise ValueError("Use only ., X, S and G.")
        self.environment = grid
        self.rows, self.cols = len(grid), len(grid[0])
        starts = [(r, c) for r in range(self.rows) for c in range(self.cols)
                  if grid[r][c] == "S"]
        goals = [(r, c) for r in range(self.rows) for c in range(self.cols)
                 if grid[r][c] == "G"]
        if len(starts) != 1 or len(goals) != 1:
            raise ValueError("Provide exactly one S and one G.")
        self.position, self.goal = starts[0], goals[0]
        self.model = [["?"] * self.cols for _ in range(self.rows)]
        self.visited = set()
        self.path = [self.position]

    def neighbours(self, position):
        r, c = position
        for dr, dc in DIRECTIONS:
            nr, nc = r + dr, c + dc
            if 0 <= nr < self.rows and 0 <= nc < self.cols:
                yield nr, nc

    def sense(self):
        # Only this method reads actual cell contents from the environment.
        for r, c in [self.position] + list(self.neighbours(self.position)):
            self.model[r][c] = self.environment[r][c]
        self.visited.add(self.position)

    def plan(self, targets):
        queue = deque([self.position])
        parent = {self.position: None}
        while queue:
            current = queue.popleft()
            if current in targets:
                path = []
                while current is not None:
                    path.append(current)
                    current = parent[current]
                return path[::-1]
            for nr, nc in self.neighbours(current):
                nxt = (nr, nc)
                if self.model[nr][nc] in ".SG" and nxt not in parent:
                    parent[nxt] = current
                    queue.append(nxt)
        return None

    def run(self):
        self.sense()
        while self.position != self.goal:
            route = self.plan({self.goal})
            if route is None:
                unexplored = {(r, c) for r in range(self.rows)
                              for c in range(self.cols)
                              if self.model[r][c] in ".SG"
                              and (r, c) not in self.visited}
                route = self.plan(unexplored)
            if route is None:
                return False
            # Follow a safe route; sense and replan after reaching its target.
            for position in route[1:]:
                self.position = position
                self.path.append(position)
                self.sense()
                if position == self.goal:
                    return True
        return True


def main():
    GRID = ["S..X.", ".X.X.", ".X...", "...X.", "XX..G"]
    agent = ModelBasedAgent(GRID)
    reached = agent.run()
    print("Goal reached!" if reached else "No route: reachable area exhausted.")
    print("Actual travel path:", agent.path)
    print("Moves:", len(agent.path) - 1)
    print("Remembered map (? = unseen):")
    for row in agent.model:
        print(" ".join(row))


if __name__ == "__main__":
    main()

Detailed Code Explanation

Function-by-function breakdown and key variables explaining the internal logic:

  • GRID is a list of equal-length strings. S is start, G is goal, . is free and X is blocked.
  • ModelBasedAgent.__init__() creates the position, known goal coordinates, visited set, actual travel path and a model initially filled with ?.
  • neighbours() generates only in-bounds up/down/left/right coordinates. It does not read hidden grid contents.
  • sense() is the only method that reads actual cell contents. It copies the current cell and its immediate neighbours into the model.
  • plan(targets) runs BFS over known free cells. Its parent dictionary both records visited search states and reconstructs a route.
  • run() first tries planning to the goal. If that fails, it plans to the nearest reachable known-free cell that the agent has not visited.
  • It follows the route, senses during movement and then replans. If no reachable exploration target remains, it reports failure.
  • The actual grid is stored for simulation, but the planner uses self.model, not the full environment.

The default example reaches the goal in 20 actual moves. This includes exploration; it is not a claim that the globally shortest route has 20 moves.

Practical 3: Informed Search - A* for 8-Puzzle

Informed Search • Manhattan Distance • Admissible Heuristic

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (15) Exam Variations

Aim & Objective

To implement the A* heuristic search algorithm to solve the 8-puzzle problem using Manhattan distance as an admissible and consistent heuristic.

Theory & Core Concepts

  • A* Evaluation Function: f(n) = g(n) + h(n), where g(n) is the exact cost from start to node n, and h(n) is the estimated remaining cost to the goal.
  • Manhattan Distance: Sum of horizontal and vertical distances of each numbered tile from its goal position: h(n) = Σ (|r_i - r_goal| + |c_i - c_goal|) for tiles 1..8. The blank tile 0 is excluded so moves are not double counted.
  • Admissibility & Consistency: Manhattan distance is admissible (never overestimates) because each sliding move can only reduce the distance of one tile by 1 grid step. It is also consistent (monotonic), guaranteeing an optimal shortest path.
  • Inversion Parity Solvability: An inversion occurs when a tile with a larger number precedes a tile with a smaller number in row-major order (ignoring 0). In a 3x3 puzzle, blank moves preserve inversion parity. Start and Goal must have the same parity (both even or both odd); otherwise the puzzle is mathematically unsolvable.

Step-by-Step Algorithm & Dry Run

  1. Validate state (all digits 0..8 present) and verify parity(start) == parity(goal).
  2. Initialize priority queue (min-heap) with (f=h(start), g=0, start).
  3. Initialize best_g = {start: 0} and parent = {start: (None, 'START')}.
  4. While frontier is not empty:
  5.   a. Pop state with lowest f. If g != best_g[current], discard stale entry.
  6.   b. If current == goal, reconstruct solution path and return.
  7.   c. Increment expanded node counter.
  8.   d. Generate legal blank swaps (UP, DOWN, LEFT, RIGHT).
  9.   e. For each neighbour, compute new_g = g + 1. If new_g < best_g[nxt], record best_g, parent, calculate f = new_g + h(nxt), and push to min-heap.

Standalone Python 3 implementation with standard library imports only (no extra packages required).

pract3.py 
"""Practical 3: A* for the 8-puzzle using Manhattan distance.
Run: python pract3.py
Edit START/GOAL in main(). Use each number 0..8 once; 0 is blank.
Move labels describe the BLANK, not the tile. Unit cost per move.
"""
import heapq


def validate(state):
    if len(state) != 9 or set(state) != set(range(9)):
        raise ValueError("A board must contain 0 through 8 exactly once.")


def parity(state):
    tiles = [x for x in state if x != 0]
    return sum(tiles[i] > tiles[j] for i in range(len(tiles))
               for j in range(i + 1, len(tiles))) % 2


def neighbours(state):
    blank = state.index(0)
    r, c = divmod(blank, 3)
    for name, dr, dc in [("UP", -1, 0), ("DOWN", 1, 0),
                         ("LEFT", 0, -1), ("RIGHT", 0, 1)]:
        nr, nc = r + dr, c + dc
        if 0 <= nr < 3 and 0 <= nc < 3:
            board = list(state)
            other = nr * 3 + nc
            board[blank], board[other] = board[other], board[blank]
            yield tuple(board), name


def manhattan(state, goal_positions):
    total = 0
    for i, tile in enumerate(state):
        if tile != 0:  # Do not count the blank.
            r, c = divmod(i, 3)
            gr, gc = goal_positions[tile]
            total += abs(r - gr) + abs(c - gc)
    return total


def astar(start, goal):
    validate(start)
    validate(goal)
    if parity(start) != parity(goal):
        return None, 0
    positions = {tile: divmod(i, 3) for i, tile in enumerate(goal)}
    frontier = [(manhattan(start, positions), 0, start)]  # (f, g, state)
    best_g = {start: 0}
    parent = {start: (None, "START")}
    expanded = 0
    while frontier:
        _, g, current = heapq.heappop(frontier)
        if g != best_g[current]:  # Discard an old, more expensive entry.
            continue
        if current == goal:
            path = []
            while current is not None:
                previous, action = parent[current]
                path.append((current, action))
                current = previous
            return path[::-1], expanded
        expanded += 1  # States whose successors are generated; excludes goal.

                parent[nxt] = (current, action)
                f = new_g + manhattan(nxt, positions)
                heapq.heappush(frontier, (f, new_g, nxt))
    return None, expanded

  • parity() counts inversions ignoring 0. A 3-by-3 start can reach a goal only if their inversion parities match.

Adversarial Search • Game Trees • Alpha-Beta Pruning

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (15) Exam Variations

Aim & Objective

To implement and compare the Minimax algorithm and Alpha-Beta pruning on a two-player zero-sum binary game tree and evaluate the reduction in visited nodes.

Theory & Core Concepts

  • Adversarial Search: Search in competitive environments where two opposing agents alternate moves. MAX aims to maximize the terminal utility, while MIN aims to minimize it.
  • Minimax Principle: Recursively computes the value of each node: MAX nodes take max(left, right), MIN nodes take min(left, right).
  • Alpha-Beta Bounds: Maintains two cutoff thresholds:
    • α (Alpha): The best (highest) score MAX can guarantee along the search path.
    • β (Beta): The best (lowest) score MIN can enforce along the search path.
  • Pruning Condition: Whenever α ≥ β, the current branch cannot affect the root decision; the search terminates immediately at that node.
  • Optimality Invariance: Alpha-Beta pruning returns the exact same root game value as full Minimax, but reduces time complexity from O(b^d) to as low as O(b^(d/2)) with optimal move ordering.

Step-by-Step Algorithm & Dry Run

  1. Validate that the leaf array length is a non-zero power of 2, and compute depth = count.bit_length() - 1.
  2. Minimax(leaves, depth, index, maximizing):
    If depth is 0, return leaves[index]. Recurse on left child 2*index and right child 2*index+1. Return max() if maximizing else min().
  3. AlphaBeta(leaves, depth, index, maximizing, α, β):
    If depth is 0, return leaves[index].
    For each child in (2*index, 2*index+1):
      Recurse and obtain child score.
      If maximizing: update value = max(value, score), α = max(α, value).
      If minimizing: update value = min(value, score), β = min(β, value).
      If α ≥ β: break (prune remaining siblings).
    Return value.

def minimax(leaves, depth, index, maximizing, stats):
    stats["nodes"] += 1
    if depth == 0:
        return leaves[index]
    left = minimax(leaves, depth - 1, 2 * index, not maximizing, stats)
    right = minimax(leaves, depth - 1, 2 * index + 1, not maximizing, stats)
    return max(left, right) if maximizing else min(left, right)


def alphabeta(leaves, depth, index, maximizing, alpha, beta, stats):
    stats["nodes"] += 1
    if depth == 0:
        return leaves[index]
    value = float("-inf") if maximizing else float("inf")
    for child in (2 * index, 2 * index + 1):
        score = alphabeta(leaves, depth - 1, child, not maximizing,
                          alpha, beta, stats)
        if maximizing:
            value = max(value, score)
            alpha = max(alpha, value)
        else:
            value = min(value, score)
            beta = min(beta, value)
        if alpha >= beta:
            break  # Remaining children cannot change the root decision.
    return value

    count = len(leaves)

    a = minimax(leaves, depth, 0, True, mm)
    b = alphabeta(leaves, depth, 0, True, float("-inf"), float("inf"), ab)
    return a, b, mm["nodes"], ab["nodes"]

Aim & Objective

To solve the classical Tower of Hanoi puzzle using Breadth-First Search (BFS) state-space exploration and verify the theoretical minimum move count 2^N - 1.

Theory & Core Concepts

  • Search vs Hardcoded Recursion: Classical Hanoi recursion follows a known divide-and-conquer strategy without state search. This practical explicitly implements state-space search using BFS to explore configurations.
  • State Representation: A 3-tuple of tuples (pegA, pegB, pegC). For N=3, start is ((3,2,1), (), ()) and goal is ((), (), (3,2,1)). Last element in each tuple represents the topmost disk.
  • Move Constraints: Only the top disk of a peg can move; a larger disk cannot be placed on top of a smaller disk.
  • BFS Guarantee: Because each move has equal cost 1, BFS explores all 1-move states, then all 2-move states, guaranteed to find the minimum move sequence (2^N - 1).

Step-by-Step Algorithm & Dry Run

  1. Define start state (tuple(N..1), (), ()) and goal state ((), (), tuple(N..1)).
  2. Initialize FIFO queue with start and parent dictionary {start: (None, 'START')}.
  3. While queue is not empty:
  4.   a. Pop current state from the front of the queue.
  5.   b. If current == goal, trace back parent pointers and return the move sequence.
  6.   c. Increment expanded nodes counter.
  7.   d. For each source peg (0..2) and target peg (0..2):
        If legal move: construct next state.
        If next state not in parent: record parent and append to queue.

"""Practical 5: Tower of Hanoi by BFS STATE-SPACE SEARCH.
Run: python pract5.py
Edit N in main(); use small values (e.g. 0 to 5) for BFS practice.
A state is (pegA, pegB, pegC); each peg is a tuple, bottom to top.
This is deliberately BFS, not the usual direct recursive Hanoi algorithm.
"""
from collections import deque


def successors(state):
    for source in range(3):
        if not state[source]:
            continue
        disk = state[source][-1]
        for target in range(3):
            if source == target:
                continue
            if state[target] and state[target][-1] < disk:
                continue
            pegs = [list(peg) for peg in state]
            pegs[source].pop()
            pegs[target].append(disk)
            nxt = tuple(tuple(peg) for peg in pegs)
            action = f"Disk {disk}: {'ABC'[source]} -> {'ABC'[target]}"
            yield nxt, action


def hanoi_bfs(n):
    if n < 0:
        raise ValueError("Number of disks cannot be negative.")
    disks = tuple(range(n, 0, -1))
    start, goal = (disks, (), ()), ((), (), disks)
    queue = deque([start])
    parent = {start: (None, "START")}  # Also acts as visited collection.
    expanded = 0
    while queue:
        current = queue.popleft()
        if current == goal:
            path = []
            while current is not None:
                previous, action = parent[current]
                path.append((current, action))
                current = previous
            return path[::-1], expanded
        expanded += 1
        for nxt, action in successors(current):
            if nxt not in parent:
                parent[nxt] = (current, action)
                queue.append(nxt)
    return None, expanded


def main():
    N = 3
    path, expanded = hanoi_bfs(N)
    for step, (state, action) in enumerate(path):
        print(f"Step {step}: {action}")
        print("  ".join(f"{name}: {list(peg)}" for name, peg in zip("ABC", state)))
    print("Moves:", len(path) - 1)
    print("Theoretical minimum:", 2 ** N - 1)
    print("Nodes expanded (excluding goal):", expanded)


if __name__ == "__main__":
    main()

CSP • Constraint Propagation • Minimum Remaining Values

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (20) Exam Variations

Aim & Objective

To solve 9x9 Sudoku puzzles using Constraint Satisfaction Problem (CSP) methods: Plain Backtracking vs Constraint Propagation with Minimum Remaining Values (MRV).

Theory & Core Concepts

  • CSP Formulation: Variables = 81 cells (empty cells are search variables); Domain = digits {1..9}; Constraints = All-Different in each row, each column, and each 3x3 subgrid.
  • Constraint Propagation: If any unfilled cell has exactly one valid candidate digit remaining, it is filled immediately as a forced assignment without branching. This repeats until no singletons remain.
  • Minimum Remaining Values (MRV): When branching is required, select the unassigned cell with the smallest domain (fewest candidates) to minimize the branching factor and detect dead ends immediately.
  • Performance Comparison: Plain backtracking makes 9,127 calls, 9,126 guesses, and 9,074 failed branches. Propagation + MRV solves the exact same puzzle in 1 call, 0 guesses, and 52 forced assignments!

Step-by-Step Algorithm & Dry Run

  1. Validate 9x9 dimensions and verify that initial clues contain no duplicate digits in any row, column, or 3x3 box.
  2. Compute legal candidate digits for any cell: DIGITS - (used_row | used_col | used_box).
  3. propagate(board): Repeatedly scan all empty cells. If any has 0 candidates, return False (contradiction). If a cell has 1 candidate, assign it and continue. When no single-candidate cells remain, return True.
  4. search(board):
      a. If improved mode: run propagate(); if contradiction, return None.
      b. Find all empty cells. If none remain, return board (solved).
      c. In improved mode: select cell with min(candidates) (MRV). In plain mode: select first empty cell.
      d. For each candidate value: create board copy, set value, recurse. If valid, return solution.
      e. Backtrack and return None.

"""Practical 6: Sudoku - backtracking, candidate propagation and MRV.
Run: python pract6.py
Edit PUZZLE in main(): nine rows of nine digits, 0 means empty.
Compare plain backtracking with repeated single-candidate propagation + MRV.
Returns the first solution; it does not prove that a puzzle has only one solution.
"""
DIGITS = set(range(1, 10))


def validate(board):
    if len(board) != 9 or any(len(row) != 9 for row in board):
        raise ValueError("Provide a 9 x 9 board.")
    if any(value not in range(10) for row in board for value in row):
        raise ValueError("Use only integers 0 to 9.")
    units = list(board)
    units += [[board[r][c] for r in range(9)] for c in range(9)]
    units += [[board[r][c] for r in range(br, br + 3)
               for c in range(bc, bc + 3)]
              for br in (0, 3, 6) for bc in (0, 3, 6)]
    for unit in units:
        filled = [value for value in unit if value]
        if len(filled) != len(set(filled)):
            raise ValueError("Invalid clues: repeated digit in a row, column or box.")


def candidates(board, r, c):
    used = set(board[r]) | {board[i][c] for i in range(9)}
    br, bc = (r // 3) * 3, (c // 3) * 3
    used |= {board[i][j] for i in range(br, br + 3)
             for j in range(bc, bc + 3)}
    return DIGITS - used


def propagate(board, stats):
    # Fill forced values until no more single-candidate cells remain.
    while True:
        changed = False
        for r in range(9):
            for c in range(9):
                if board[r][c] != 0:
                    continue
                options = candidates(board, r, c)
                if not options:
                    return False  # Contradiction: undo this branch.
                if len(options) == 1:
                    board[r][c] = next(iter(options))
                    stats["forced"] += 1
                    changed = True
        if not changed:
            return True


def solve_sudoku(puzzle, improved=True):
    validate(puzzle)
    stats = {"calls": 0, "guesses": 0, "forced": 0, "failed_branches": 0}

    def search(board):
        stats["calls"] += 1
        if improved and not propagate(board, stats):
            stats["failed_branches"] += 1
            return None
        empty = [(r, c) for r in range(9) for c in range(9) if board[r][c] == 0]
        if not empty:
            return board
        if improved:
            r, c = min(empty, key=lambda cell: len(candidates(board, *cell)))
        else:
            r, c = empty[0]
        for value in sorted(candidates(board, r, c)):
            stats["guesses"] += 1
            copy = [row[:] for row in board]  # Isolate changes in each branch.
            copy[r][c] = value
            result = search(copy)
            if result is not None:
                return result
        stats["failed_branches"] += 1
        return None

    solution = search([row[:] for row in puzzle])
    return solution, stats

Practical 7: Combinatorial Optimization - TSP with Local Beam Search

Combinatorial Optimization • Heuristic Search • NP-Hard

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (20) Exam Variations

Aim & Objective

To solve the Traveling Salesman Problem (TSP) using Local Beam Search with beam width k and 2-city swap neighbourhood.

Theory & Core Concepts

  • TSP Formulation: Find a Hamiltonian cycle that visits all n cities exactly once and returns to the starting city with minimum total travel cost. NP-hard combinatorial problem.
  • Local Beam Search: Instead of retaining only 1 current state (like Hill Climbing), Local Beam Search maintains k candidate tours in parallel.
  • Neighbourhood Operator (2-City Swap): City 0 is anchored at the start to eliminate cyclic rotational duplicates. Neighbours are formed by swapping any pair of cities at indices 1 <= i < j < n.
  • Elitist Pooling: Combines current beam tours and all generated neighbours into a shared pool, evaluates total cost (including return edge), and retains the k best distinct tours for the next iteration.
  • Incomplete Heuristic: Beam search is not guaranteed to find the global optimum; it can get trapped in local plateaus or lose diversity.

Step-by-Step Algorithm & Dry Run

  1. Validate square distance matrix and positive beam width k and max_iterations.
  2. Generate k distinct random initial permutations with city 0 fixed.
  3. Evaluate tour costs: sum consecutive edge weights plus edge returning from last city to city 0.
  4. Iterate up to max_iterations:
      a. Initialize candidate pool with current beam.
      b. For each tour in beam, generate all 2-city swap neighbours and add to pool.
      c. Sort pool by (tour_cost, tour) and select top k distinct tours.
      d. If the new beam is identical to the previous beam, break (stabilized).
      e. Update beam = next_beam.
  5. Return best-found tour and cost history.

"""Practical 7: Local Beam Search for the Traveling Salesman Problem.
Run: python pract7.py
Edit DISTANCES, K, MAX_ITERATIONS and SEED in main(). Complete cost matrix.
Keep city 0 first; swap two other cities to generate neighbours.
Elitist variant: select k best DISTINCT tours from current tours + neighbours.
A best-found tour is NOT a general guarantee of the global optimum.
"""
import random
from math import factorial, isfinite


def tour_cost(tour, distances):
    return sum(distances[tour[i]][tour[(i + 1) % len(tour)]]
               for i in range(len(tour)))  # Includes return to start.


def neighbours(tour):
    for i in range(1, len(tour) - 1):
        for j in range(i + 1, len(tour)):
            copy = list(tour)
            copy[i], copy[j] = copy[j], copy[i]
            yield tuple(copy)


def local_beam_search(distances, k=3, max_iterations=100, seed=7):
    n = len(distances)
    if n < 2 or any(len(row) != n for row in distances):
        raise ValueError("Provide a square matrix for at least two cities.")
    if any(not isfinite(v) or v < 0 for row in distances for v in row):
        raise ValueError("Distances must be finite and nonnegative.")
    if k < 1 or max_iterations < 1:
        raise ValueError("Beam width and iteration limit must be positive.")
    # Fixing city 0 leaves (n-1)! distinct permutations, including reverse tours.
    k = min(k, factorial(n - 1))
    rng = random.Random(seed)
    initial = set()
    while len(initial) < k:
        initial.add((0,) + tuple(rng.sample(range(1, n), n - 1)))
    rank = lambda tour: (tour_cost(tour, distances), tour)
    beam = sorted(initial, key=rank)
    history = [tour_cost(beam[0], distances)]
    for _ in range(max_iterations):
        pool = set(beam)
        for tour in beam:
            pool.update(neighbours(tour))
        next_beam = sorted(pool, key=rank)[:k]
        history.append(tour_cost(next_beam[0], distances))
        if next_beam == beam:
            break  # Whole beam is unchanged, not merely its best cost.
        beam = next_beam
    return beam[0], tour_cost(beam[0], distances), history


def main():
    DISTANCES = [[0, 10, 15, 20, 25],
                 [10, 0, 35, 25, 17],
                 [15, 35, 0, 30, 28],
                 [20, 25, 30, 0, 16],
                 [25, 17, 28, 16, 0]]
    K, MAX_ITERATIONS, SEED = 3, 100, 7
    tour, cost, history = local_beam_search(DISTANCES, K, MAX_ITERATIONS, SEED)
    print("Best-found tour:", " -> ".join(str(city) for city in tour + (tour[0],)))
    print("City labels: 0=A, 1=B, 2=C, 3=D, 4=E")
    print("Best-found cost:", cost)
    print("Best cost at initialization and after each iteration:", history)
    print("Local Beam Search does not guarantee the global optimum.")


if __name__ == "__main__":
    main()

Detailed Code Explanation

Function-by-function breakdown and key variables explaining the internal logic:

  • DISTANCES[i][j] gives the travel cost from city i to city j.
  • A tour is a permutation of city indices. City 0 is fixed at the start to avoid storing rotated copies of the same cycle.
  • tour_cost() sums consecutive edge costs. (i+1)%len(tour) includes the last-to-first edge.
  • neighbours() swaps two positions after position 0, preserving a valid permutation.
  • local_beam_search() validates a complete, finite, nonnegative square matrix and positive k/iteration count.
  • random.Random(seed) generates reproducible initial tours for practice.
  • Beam width is capped at (n-1)!, the number of available permutations with city 0 fixed, preventing a request for impossible numbers of distinct initial tours.
  • pool=set(beam) combines current tours and new neighbours without duplicates. This is an elitist variant: existing good tours remain eligible.
  • Sort by (tour_cost, tour) and keep [:k]. The tour itself breaks equal-cost ties deterministically.
  • Stop when the whole beam is unchanged or the iteration limit is reached. A single unchanged best cost is not enough to prove the beam has stopped changing.

Practical 8: Uninformed Planning - BFS for 8-Puzzle

Classical Planning • Uninformed Search • Breadth-First Search

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (20) Exam Variations

Aim & Objective

To generate an optimal action plan for solving the 8-puzzle using Breadth-First Search (BFS) in state space.

Theory & Core Concepts

  • Planning as State-Space Search: Classical planning problems find an action sequence taking the world from initial state S0 to a goal state G.
  • BFS Planning Properties: Explores state space level by level in order of move count. For unit step costs, BFS is guaranteed to find a plan with the minimum number of actions.
  • Informed (P3) vs Uninformed (P8): Practical 3 uses A* with Manhattan heuristic guidance; Practical 8 uses pure uninformed BFS. BFS expands states radially without goal distance estimates.
  • Data Structures: Uses collections.deque for O(1) FIFO pops, and a parent dictionary mapping child states to (parent_state, action) for cycle prevention and path reconstruction.

Step-by-Step Algorithm & Dry Run

  1. Validate start and goal board states and ensure identical inversion parity.
  2. Initialize queue deque([start]) and parent = {start: (None, 'START')}.
  3. While queue has states:
      a. Pop oldest state: current = queue.popleft().
      b. If current == goal: trace back parent chain, reverse, and return plan.
      c. Increment expanded count.
      d. Generate legal blank movements (UP, DOWN, LEFT, RIGHT).
      e. If neighbour not in parent dictionary: record parent immediately and append to queue.

"""Practical 8: BFS planning using the 8-puzzle.
Run: python pract8.py
Edit START/GOAL in main(). 0 means blank; actions move the blank.
Standalone file: does not import pract3.py. BFS gives fewest unit-cost moves.
"""
from collections import deque


def validate(state):
    if len(state) != 9 or set(state) != set(range(9)):
        raise ValueError("Use 0 through 8 exactly once.")


def parity(state):
    tiles = [x for x in state if x != 0]
    return sum(tiles[i] > tiles[j] for i in range(len(tiles))
               for j in range(i + 1, len(tiles))) % 2


def neighbours(state):
    blank = state.index(0)
    r, c = divmod(blank, 3)
    for action, dr, dc in [("UP", -1, 0), ("DOWN", 1, 0),
                           ("LEFT", 0, -1), ("RIGHT", 0, 1)]:
        nr, nc = r + dr, c + dc
        if 0 <= nr < 3 and 0 <= nc < 3:
            board = list(state)
            other = 3 * nr + nc
            board[blank], board[other] = board[other], board[blank]
            yield tuple(board), action


def bfs(start, goal):
    validate(start)
    validate(goal)
    if parity(start) != parity(goal):
        return None, 0
    queue = deque([start])
    parent = {start: (None, "START")}
    expanded = 0
    while queue:
        current = queue.popleft()
        if current == goal:
            path = []
            while current is not None:
                previous, action = parent[current]
                path.append((current, action))
                current = previous
            return path[::-1], expanded
        expanded += 1
        for nxt, action in neighbours(current):
            if nxt not in parent:  # Mark visited when enqueued.
                parent[nxt] = (current, action)
                queue.append(nxt)
    return None, expanded


def main():
    START = (1, 2, 3, 4, 0, 6, 7, 5, 8)
    GOAL = (1, 2, 3, 4, 5, 6, 7, 8, 0)
    path, expanded = bfs(START, GOAL)
    if path is None:
        print("No solution: initial and goal inversion parities differ.")
        return
    for step, (board, action) in enumerate(path):
        print(f"Step {step}: {action}")
        for i in range(0, 9, 3):
            print(*board[i:i + 3])
    print("Moves:", len(path) - 1)
    print("Nodes expanded (excluding goal):", expanded)


if __name__ == "__main__":
    main()

Practical 9: Uninformed Search - DFS for Water Jug Problem

Uninformed Search • Depth-First Search • LIFO Stack

Aim Theory Algorithm Source Code Code Explanation Output Viva Voce (17) Exam Variations

Aim & Objective

To solve the classical Water Jug Problem using Depth-First Search (DFS) with a LIFO stack.

Theory & Core Concepts

  • Problem Formulation: Two jugs with integer capacities A and B without markings, measuring target quantity T in either jug. Initial state is (0, 0).
  • Six Elementary Operations:
    1. Fill Jug A: (A, b)
    2. Fill Jug B: (a, B)
    3. Empty Jug A: (0, b)
    4. Empty Jug B: (a, 0)
    5. Pour A into B: (a - t, b + t), where t = min(a, B - b)
    6. Pour B into A: (a + t, b - t), where t = min(b, A - a)
  • Diophantine Solvability Condition: Target T can be measured if and only if T <= max(A, B) and T is divisible by gcd(A, B).
  • DFS Characteristics: Uses LIFO stack. Explores deep branches before backtracking. Path depends on operator ordering; finds a valid path, but is not guaranteed to be shortest.

Step-by-Step Algorithm & Dry Run

  1. Validate capacities A, B > 0 and target >= 0.
  2. Check solvability: if target > max(A, B) or target % gcd(A, B) != 0, return None.
  3. Initialize stack [(0, 0)] and parent = {(0, 0): (None, 'START')}.
  4. While stack is not empty:

      c. Generate all 6 successors using capacity limits.
      d. For each unvisited successor: record parent and push to stack.

"""Practical 9: DFS for the Water Jug Problem.
Run: python pract9.py
Edit CAPACITY_A, CAPACITY_B, TARGET in main(). Positive integer capacities.
State=(water in A, water in B); goal is TARGET in EITHER jug.
DFS returns a valid path, not necessarily the shortest path.
"""
from math import gcd


def successors(state, capacity_a, capacity_b):
    a, b = state
    a_to_b = min(a, capacity_b - b)
    b_to_a = min(b, capacity_a - a)
    return [((capacity_a, b), "Fill A"),
            ((a, capacity_b), "Fill B"),
            ((0, b), "Empty A"),
            ((a, 0), "Empty B"),
            ((a - a_to_b, b + a_to_b), "Pour A -> B"),
            ((a + b_to_a, b - b_to_a), "Pour B -> A")]


def water_jug_dfs(capacity_a, capacity_b, target):
    if capacity_a <= 0 or capacity_b <= 0 or target < 0:
        raise ValueError("Capacities must be positive and target nonnegative.")
    if target > max(capacity_a, capacity_b) or target % gcd(capacity_a, capacity_b):
        return None
    start = (0, 0)
    stack = [start]
    parent = {start: (None, "START")}
    while stack:
        current = stack.pop()  # Last In, First Out.
        if target in current:
            path = []
            while current is not None:
                previous, action = parent[current]
                path.append((current, action))
                current = previous
            return path[::-1]
        for nxt, action in successors(current, capacity_a, capacity_b):
            if nxt not in parent:
                parent[nxt] = (current, action)
                stack.append(nxt)
    return None


def main():
    CAPACITY_A, CAPACITY_B, TARGET = 4, 3, 2
    path = water_jug_dfs(CAPACITY_A, CAPACITY_B, TARGET)
    if path is None:
        print("No solution for these capacities and target.")
        return
    for step, ((a, b), action) in enumerate(path):
        print(f"{step}. {action}: Jug A={a} litres, Jug B={b} litres")
    print("Operations:", len(path) - 1)
    print("Goal reached. DFS does not guarantee the shortest path.")


if __name__ == "__main__":
    main()

  • A state (a,b) means a litres in jug A and b litres in jug B. Initially (0,0).

Aim & Objective

To solve the 8-Queens problem and evaluate the efficiency gains of Backtracking with Forward Checking compared to Plain Backtracking.

Theory & Core Concepts

  • Problem Formulation: Place 8 queens on an 8x8 chessboard such that no two queens attack each other along any row, column, or diagonal.
  • Representation: 1D array queens[row] = col. Each row naturally receives at most one queen.
  • Conflict Conditions: Queens at (r, col_r) and (row, col) conflict if:
    • col_r == col (same column)
    • abs(col_r - col) == row - r (same diagonal)
  • Forward Checking Lookahead: Whenever a queen is placed at (row, col), immediately look ahead and remove col, col - delta, col + delta from the candidate domains of all remaining future rows later > row.
  • Early Wipeout Detection: If any future row's domain becomes empty (domain wipeout), backtrack immediately without descending further into that branch.
  • Quantitative Result: Both find all 92 valid arrangements. Plain backtracking makes 2,057 recursive calls and tries 15,720 candidates. Forward checking makes only 1,165 calls, tries 1,724 candidates, and detects 560 domain wipeouts early!

Step-by-Step Algorithm & Dry Run

  1. Initialize queens = [-1] * n.
  2. search(row, domains):
      a. If row == n: store solution copy and return.
      b. Determine options: sorted domain for current row (in FC) or range(n) (in plain).
      c. For each column option:
        • If unsafe: skip.
        • Place queen: queens[row] = col.
        • In FC mode: prune attacked columns from future row domains. If any future domain wipes out, record wipeout and do not recurse.
        • If safe: recurse to row + 1.
        • Backtrack: reset queens[row] = -1.

"""Practical 10: N-Queens - plain backtracking and forward checking.
Run: python pract10.py
Edit N in main() (default 8). Finds ALL solutions and prints the first.
Both modes count recursive calls identically, including complete solutions.
One variable per row; its value is the queen's column (zero-based).
"""


def safe(queens, row, col):
    for r in range(row):
        if queens[r] == col or abs(queens[r] - col) == row - r:
            return False
    return True


def solve_queens(n=8, forward_checking=False):
    if n < 1:
        raise ValueError("N must be positive.")
    queens = [-1] * n
    solutions = []
    stats = {"calls": 0, "candidates_tried": 0, "domain_wipeouts": 0}

    def search(row, domains):
        stats["calls"] += 1
        if row == n:
            solutions.append(queens.copy())  # Save an independent solution.
            return
        options = sorted(domains[row]) if forward_checking else range(n)
        for col in options:
            stats["candidates_tried"] += 1
            if not safe(queens, row, col):
                continue
            queens[row] = col
            if forward_checking:
                next_domains = [domain.copy() for domain in domains]
                possible = True
                for later in range(row + 1, n):
                    delta = later - row
                    next_domains[later] -= {col, col - delta, col + delta}
                    if not next_domains[later]:
                        possible = False
                        break
                if possible:
                    search(row + 1, next_domains)
                else:
                    stats["domain_wipeouts"] += 1
            else:
                search(row + 1, domains)
            queens[row] = -1  # Backtrack even after recording a solution.

    search(0, [set(range(n)) for _ in range(n)])
    return solutions, stats


def main():
    N = 8
    for use_fc in (False, True):
        solutions, stats = solve_queens(N, use_fc)
        print("\nForward checking" if use_fc else "\nPlain backtracking")
        print("Total solutions:", len(solutions))
        if solutions:
            first = solutions[0]
            print("First solution, columns by row:", first)
            for col in first:
                print(" ".join("Q" if c == col else "." for c in range(N)))
        else:
            print("No solution.")
        print("Statistics for ALL solutions:", stats)


if __name__ == "__main__":
    main()

  • solve_queens() defines recursive search(row,domains).

"""Practical 11: Rule-based chatbot with regex pattern matching.

Add a (pattern, response) pair to RULES to extend the chatbot.
First matching rule wins. Specific rules precede general greetings.

import re

RULES = [
    (r"\bmy name is (?P<name>[a-z]+(?: [a-z]+)*)$",
     "Nice to meet you, {name}!"),
    (r"\bwhat is your name\b", "I am AI-Bot, a rule-based chatbot."),
    (r"\bhow are you\b", "I am fine, thank you!"),
    (r"\bi (?:am(?: feeling)?|feel) (?P<mood>happy|excited|good)\b",
     "Glad you feel {mood}!"),
    (r"\bi (?:am(?: feeling)?|feel) (?P<mood>[a-z]+)\b",
     "You said you feel {mood}. Thank you for sharing."),
    (r"\b(artificial intelligence|ai)\b",
     "AI builds systems that perform tasks such as reasoning and problem solving."),
    (r"\bchatbot\b", "A chatbot is a program that converses with a user."),
    (r"\b(language|python)\b", "I am written in Python using the re module."),
    (r"\b(pattern matching|regular expressions?)\b",
     "Pattern matching checks input against predefined text patterns."),
    (r"\b(thanks|thank you)\b", "You are welcome!"),
    (r"\b(hello|hi|hey)\b", "Hello! How can I help you?")
]
DEFAULT = "I do not have a rule for that. Try asking about AI or chatbots."


def preprocess(text):
    text = text.lower().strip()
    text = re.sub(r"[^\w\s]", " ", text)  # Replace punctuation with spaces.
    return " ".join(text.split())  # Collapse repeated spaces.


def respond(user_input):
    text = preprocess(user_input)
    if re.fullmatch(r"bye|goodbye|exit|quit", text):
        return "Goodbye!", True
    if not text:
        return "Please type a message.", False
    for pattern, reply in RULES:
        match = re.search(pattern, text)
        if match:
            values = match.groupdict()
            if "name" in values:
                values["name"] = values["name"].title()
            return reply.format(**values), False
    return DEFAULT, False


def main():
    print("AI-Bot: Hello! Type bye, goodbye, exit or quit to stop.")
    while True:
        try:
            message = input("You: ")
        except (EOFError, KeyboardInterrupt):
            print("\nAI-Bot: Goodbye!")
            break
        reply, stop = respond(message)
        print("AI-Bot:", reply)
        if stop:
            break


if __name__ == "__main__":
    main()

Universal Python Viva Questions (Top 15)

These 15 Python questions are repeatedly asked by examiners regardless of which practical you draw:

Q1. List versus tuple?
A list can be changed; a tuple cannot. Tuples containing hashable values can be dictionary keys or set elements.
Q2. Why use a set?
For unique elements and efficient membership tests, typically O(1) average time.
Q3. Why use a dictionary?
To associate states with parents/costs or labels with values; lookup is typically O(1) average time.
Q4. What does `yield` do?
It returns the next item from a generator while preserving the function's state for later iteration.
Q5. What does `return None` mean?
The function returns Python's absence value. In these searches it often signals no solution.
Q6. Why distinguish `None` from an empty list?
An empty path or collection can sometimes be a valid result; explicitly checking is None avoids confusing it with failure.
Q7. What does `if __name__ == "__main__"` do?
It runs the demonstration only when the file is executed directly, allowing functions to be imported without starting the demo.
Q8. What is a base case?
The condition that ends recursion, such as all rows assigned or depth zero.
Q9. What is a shallow copy?
A new outer container that still refers to nested objects. For a grid, copying each row separately is needed when rows will be modified.
Q10. Why avoid `[[0]*9]*9` for an editable Sudoku?
It repeats references to the same row. A change in one row can appear in all rows. Use a comprehension to create separate rows.
Q11. What does `[::-1]` do?
It returns a reversed sequence; parent reconstruction uses it to put a goal-to-start trace into start-to-goal order.
Q12. What is a priority queue?
A structure that removes the item with the best priority, not necessarily the oldest or newest item.
Q13. What are completeness and optimality?
Completeness means finding a solution if one exists under stated assumptions; optimality means returning a best-cost solution.
Q14. What is a branching factor?
The number of successors per state, or an upper/average value used in search analysis.
Q15. What is the difference between a state and a node?
A state describes the world; a search node may additionally store a path, cost, parent and action. Several search nodes can represent the same state.
